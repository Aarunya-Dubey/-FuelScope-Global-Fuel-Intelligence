# FuelScope – Global Fuel Intelligence

FuelScope is an interactive data analytics project exploring global fuel prices and taxation trends from **2020 to 2026**. The project covers **84 countries**, **7 regions**, and more than **27,000 records**, presenting insights through Tableau dashboards and three analytical stories.

## 📌 Project Overview

The project examines how fuel prices, taxation, subsidies, and regional economic differences shape energy costs around the world. It includes comparisons of petrol, diesel, and LPG prices, along with country- and region-level trends.

## ✨ Key Features

- Interactive Tableau dashboard for exploring global fuel prices and taxation.
- Three Tableau stories presenting policy, supply-chain, and economic perspectives.
- Comparisons of petrol, diesel, and LPG prices.
- Analysis of fuel taxation and government subsidy indicators.
- Responsive website design with dark and light themes.
- Smooth navigation and GSAP-powered animations.
- Global energy insights through interactive visualizations.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GSAP (Animations)
- Tableau Public (Data Visualization)
- GitHub Pages (Website Hosting)

## 📁 Dataset Information

The analysis uses a dataset covering **2020–2026**, with:
- 84 countries
- 7 global regions
- More than 27,000 records
- Petrol, diesel, and LPG prices
- Fuel taxation and subsidy indicators
- Economic and regional comparisons

## 🚀 How to Run the Website Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Alternatively, use the Live Server extension in VS Code.
5. Keep an internet connection available to load Tableau visualizations.

## 🌐 GitHub Pages Deployment

1. Upload the project files to your GitHub repository.
2. Open **Settings → Pages**.
3. Under Build and Deployment, select **Deploy from a branch**.
4. Choose the `main` branch.
5. Select the `/ (root)` folder.
6. Click **Save**.
7. Wait for GitHub Pages to publish your website.

## 🎯 Project Objective

The main objective of FuelScope is to transform complex global fuel data into meaningful visual insights. It helps users understand energy-price movements, taxation patterns, government subsidies, and their potential impact on public policy, businesses, and the global economy.
